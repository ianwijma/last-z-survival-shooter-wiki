# Authoring intent

The M4A1 is a mid-tier assault rifle. The page should emphasize:

- Baseline stats vs competitors (AK47, SCAR)
- How Fast Mag attachments change viability
- Common meta loadouts

If sources disagree on damage numbers, show both values with patch version
annotations. Keep prose under 600 words total; data belongs in tables.

## Section hints

### stats
Table format. Columns: damage, reload time, magazine, fire rate, effective
range. If a stat is unknown, write `—`; never guess.

### recommended-loadouts
Group loadouts by playstyle (aggressive, ranged, defensive). Cite the
source for each loadout (YouTube video + timestamp, or Reddit thread).

### notable-patches
Only list patches that changed this weapon's stats. One-line per change
with patch version and citation.
