# Authoring intent

This is the landing page for the Last Z: Survival Shooter wiki. The page
should:

- Briefly describe what the wiki covers (weapons, enemies, maps,
  mechanics, seasons, strategies, and lore)
- Link to each category's landing page
- Welcome contributors and explain how to contribute via GitHub PRs

Keep the overview concise. The page should orient new visitors quickly
and direct them to the content they're looking for.
